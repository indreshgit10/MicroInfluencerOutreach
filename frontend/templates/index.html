EDXSO AI Engineer Intern – Assignment 1 Architecture

This automated system is an enterprise-grade micro-influencer discovery, classification, enrichment, personalization, and outreach pipeline built strictly to specification.

1. Influencer Discovery (≥ 50 Records)

Fetches real creators across YouTube, Instagram, and developer communities in the Technology & AI niche. Implements strict zero-fabrication policies: all profile links, follower counts, and engagement metrics correspond to actual public accounts.

2. Multi-Criteria Filtering

Applies a rule-based classification engine evaluating Follower Count (5k–100k micro-influencer window), Engagement Rate (≥ 1.5%), Category relevance, and Brand-Fit safety. Clearly identifies which influencers passed or failed with granular reasons.

3. Profile Enrichment

Populates all mandatory and optional metadata fields. Contact emails are validated; missing addresses are strictly designated as Not Found rather than guessed. Calculates active reach and custom collaboration angles.

4. AI Message Personalization

Dual-message generation per shortlisted creator:

  • Email Pitch: Strictly 60–90 words, referencing niche, tone, recent content, audience, and value proposition.
  • Instagram DM: Strictly 15–30 words, punchy, conversational, and personalized.

5. Sending Layer & Tracking

Implements idempotent duplicate prevention (hashed by recipient email/profile), simulation sandbox mode with MIME payload validation, SMTP dispatch capability, and Instagram DM manual copy workflow.

6. CLI & Automated Testing

Full headless CLI execution via python run_pipeline.py, complete unit test suite via python -m unittest discover tests, and exportable datasets in both JSON and CSV formats.
